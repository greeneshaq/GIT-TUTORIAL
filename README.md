# Interactive Info App

A simple, interactive Python program built and managed on Fedora Linux. 

## Description
This repo was done as a tutorial into Git, I first created a directory on my local Linux machine and added a script file using nano.py to git. This script showcases basic Python capabilities. When executed, it displays default developer profile information and then prompts the user to input their own name to generate a personalized greeting. The collaborators for this project are myself Shaquan and my colleague Quan.

## How to Run
Make sure you have Python 3 installed, then run the script in your terminal:
```bash
python3 info.py
```
